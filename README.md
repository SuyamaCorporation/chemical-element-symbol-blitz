# 元素記号 ブリッツクイズ（周期表 120秒）

120秒間で元素名→記号・記号→元素名を何問正解できるかのブリッツゲームです。

## 機能

- 全118元素収録（H〜Og）
- 3方向モード: 名前→記号 / 記号→名前 / 両方ランダム
- 族別フィルタ: 全て / アルカリ金属 / ハロゲン / 希ガス / 遷移金属
- 4択選択形式・回答後0.7秒で次の問題へ自動遷移
- 自己ベスト記録（localStorage）

## 技術仕様

- 静的SPA（単一 index.html）
- Tailwind CSS CDN
- XSS対策: textContent で表示（innerHTML への直接挿入なし）
- localStorage: 自己ベストスコアの保存に使用
